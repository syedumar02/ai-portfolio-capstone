# AI Portfolio Website Content Creator **Student:** Syed Umar.T **Course:** B.Tech Information Technology — Second Year **Project Type:** Capstone Project ## 1. Problem Statement Creating a professional personal portfolio can be challenging for students who are still developing their technical and communication skills. Writing clear project descriptions, presenting skills, and organizing information requires planning and editing. This project explores how artificial intelligence can assist with creating, reviewing, and improving personal portfolio content. ## 2. Objectives - Create a personal portfolio website. - Develop clear About, Skills, Projects, and Contact sections. - Use AI tools to draft and improve content. - Create a case study documenting the project workflow. - Verify AI-generated information and correct errors. - Compare content before and after AI-assisted editing. - Collect feedback from three reviewers. - Document prompts, tools, limitations, and ethical considerations. ## 3. Technology Stack - HTML — website structure. - CSS — website styling and responsive layout. - GitHub — source code repository. - GitHub Pages — website hosting. - AI writing and design tools — to be documented as they are used. ## 4. Project Workflow ### Step 1: Planning Identify the target audience, website sections, project goals, and evaluation criteria. ### Step 2: Content Creation Use carefully designed AI prompts to develop draft introductions, skills descriptions, and project summaries. ### Step 3: Human Review Review the drafts to ensure they accurately represent my education, skills, interests, and completed work. ### Step 4: Website Development Build the website using HTML and CSS, store the files in GitHub, and publish the website with GitHub Pages. ### Step 5: Testing Check the website on different screen sizes, test navigation links, and review the generated content for factual errors. ### Step 6: Improvement Collect feedback, record corrections, and revise the website. ## 5. AI Tools and Prompt Engineering I will document at least four free-tier AI tools used during the project. For each tool, I will record: - Tool name and purpose. - Prompt used. - Output generated. - Errors or limitations identified. - Human corrections made. ## 6. Testing and Verification The following checks will be recorded during testing: - Accuracy of personal and technical information. - Spelling and grammar. - Working navigation links. - Correct page styling. - Mobile responsiveness. - Accessibility and readability. - Appropriate use of images and other assets. Actual test results will be added after testing. ## 7. Before-and-After Analysis I will compare an original content draft with its AI-assisted revision. The comparison will evaluate clarity, grammar, organization, accuracy, and suitability for a student portfolio. I will include a real example and explain which changes I accepted, modified, or rejected. ## 8. Ethics, Privacy, and Limitations - Do not invent skills, achievements, or project results. - Verify factual claims before publishing. - Avoid sharing sensitive personal information with AI tools. - Review licensing conditions before using images or generated assets. - Recognize that AI can produce inaccurate or generic content. - Keep human judgment and responsibility in the publishing process. ## 9. Reviewer Feedback Feedback will be collected from three reviewers. For each reviewer, I will document: - The feedback received. - The issue or suggestion identified. - The changes made in response. - Any suggestions that were not adopted and why. ## 10. Conclusion This project demonstrates how AI can support personal portfolio content creation when combined with human review, technical development, verification, and responsible use. The final result will be evaluated based on content quality, functionality, accuracy, reviewer feedback, and the documented AI workflow.
