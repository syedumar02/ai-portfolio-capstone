CAPSTONE PROJECT

AI Portfolio Website Content Creator

Exploring how artificial intelligence can help create clear, professional, and accurate personal portfolio content.

Back to Portfolio

1. Problem Statement

Creating a personal portfolio requires clear writing, project descriptions, visual design, and organized presentation. Students may find it difficult to communicate their skills and project experiences effectively.

This project investigates how AI tools can assist with drafting, editing, organizing, and presenting portfolio content while keeping the student responsible for accuracy and final decisions.

2. Project Objectives

  • Create clear About, Skills, Projects, and Contact sections.
  • Use AI tools to draft and improve portfolio content.
  • Develop at least one detailed project case study.
  • Verify AI-generated information and correct errors.
  • Collect feedback and revise the portfolio.
  • Document prompts, tools, workflow, and ethical considerations.

3. AI-Assisted Workflow

Step 1: Plan

Identify the target audience, portfolio sections, and goals.

Step 2: Generate

Use AI to draft introductions, project summaries, and headings.

Step 3: Verify

Check factual claims and remove unsupported statements.

Step 4: Improve

Edit the content, review the design, and gather feedback.

4. Tools Used

Record the AI tools actually used in your project. Potential tools include ChatGPT for drafting, Gemini for alternative suggestions, Canva for graphics, and Grammarly for proofreading.

For each tool, document its purpose, the prompts used, the output produced, and the corrections you made.

5. Testing and Verification

AI-generated content must be reviewed before publication. Check spelling, grammar, factual claims, project descriptions, broken links, mobile layout, and accessibility.

Maintain a testing record showing the original output, the problem identified, the correction made, and the final result.

6. Before-and-After Comparison

Before

Record your original project description or first draft before using AI.

After

Add the revised version and explain how it became clearer, more accurate, or better organized.

Replace these instructions with a real example from your project after you complete the comparison.

7. Ethics and Limitations

  • Verify AI-generated claims instead of assuming they are true.
  • Do not invent skills, achievements, or project results.
  • Protect private information when using AI tools.
  • Check image, text, and asset licensing before publication.
  • Disclose meaningful AI assistance where appropriate.
  • Keep human judgment and editing in the final publishing process.

8. Conclusion

This project explores AI as a support tool for portfolio development. Its value depends on effective prompts, verification, thoughtful editing, feedback, and responsible use. The final portfolio should reflect the student's actual skills and work.
