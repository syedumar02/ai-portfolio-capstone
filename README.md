# AI Portfolio Website Content Creator

**B.Tech Information Technology — Capstone Project**

## About the Project
This project focuses on creating and improving a personal portfolio website with the assistance of AI tools. The portfolio presents my background, technical skills, projects, learning goals, and contact information.

AI tools were used to help develop and refine the website content, review writing quality, and prepare project documentation.

## Live Portfolio
Visit my published portfolio:  
https://syedumar02.github.io/ai-portfolio-capstone/

## GitHub Repository
https://github.com/syedumar02/ai-portfolio-capstone

## Features
- Personal introduction and About section
- Technical skills and learning goals
- Projects section
- Dedicated case study page
- Contact section and GitHub profile link
- Custom portfolio banner
- Responsive website layout
- AI-assisted content creation and review

## AI Tools Used
- **ChatGPT:** Portfolio content, documentation, prompt development, and banner creation.
- **Google Gemini:** Portfolio content review.
- **Grammarly:** Grammar and clarity review.
- **Microsoft Copilot:** Project description review.

## Project Documentation
The `documentation` folder contains:

- `ai-tools.md` — AI tools used and their contributions.
- `before-after-analysis.md` — Comparison of original and improved content.
- `ethics-and-privacy.md` — Ethical considerations, privacy, and limitations.
- `evidence-report.md` — Summary of reviewer feedback, improvements, and project checks.
- `portfolio-feedback.md` — Feedback from three reviewers and improvements made.
- `verification-report.md` — Content verification and testing notes.

The `prompts` folder contains the prompt library used during the project.
