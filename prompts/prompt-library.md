## AI Portfolio Website Content Creator

**Student:** Syed Umar T  
**Course:** B.Tech Information Technology — Second Year

## 1. Purpose

This document records the prompts used during the development of my AI-assisted personal portfolio. The prompts are designed to generate useful drafts while ensuring that the final content accurately reflects my skills, interests, and project work.

## 2. Prompt 1 — Personal Portfolio Introduction

**Objective:** Create a clear and professional introduction.

**Prompt:**

"You are a portfolio content writing assistant. Help me write a concise personal introduction for a second-year B.Tech Information Technology student interested in software development and artificial intelligence. My current skills are HTML, CSS, and Python. Use a professional but approachable tone. Do not invent achievements, certifications, experience, or skills. Keep the introduction under 100 words."

**Expected output:** A concise introduction suitable for the homepage.

**Verification:** Check that the introduction reflects my actual education, skills, and interests.

## 3. Prompt 2 — About Me Section

**Objective:** Develop a readable About Me section.

**Prompt:**

"Write an About Me section for a second-year B.Tech IT student named Syed Umar T. My interests are software development and artificial intelligence, and my current technical skills include HTML, CSS, and Python. Use clear language, avoid exaggerated claims, and keep the section between 100 and 150 words. Do not invent personal achievements."

**Expected output:** A personalized About Me section.

**Verification:** Compare every personal and technical claim with my actual background.

## 4. Prompt 3 — Project Description

**Objective:** Write a project summary for a portfolio.

**Prompt:**

"Help me write a project description for my capstone, AI Portfolio Website Content Creator. The website uses HTML and CSS and is hosted through GitHub Pages. The project investigates how AI can assist with portfolio content creation, prompt engineering, verification, and responsible AI use. Clearly distinguish completed features from planned work. Do not claim that testing, automation, or reviewer feedback has been completed unless I provide evidence."

**Expected output:** An accurate project summary.

**Verification:** Confirm that the description matches the actual implementation.

## 5. Prompt 4 — Content Improvement

**Objective:** Improve clarity and grammar without changing the facts.

**Prompt:**

"Review the portfolio text below for grammar, clarity, readability, and professional tone. Preserve the original meaning and all factual details. Do not add achievements, technical skills, statistics, or experience that are not present in the source text. Return the revised version and list the major changes."

**Expected output:** An improved draft and a summary of edits.

**Verification:** Compare the revised version against the original to ensure that no unsupported claims were added.

## 6. Prompt 5 — Case Study Planning

**Objective:** Organize the capstone documentation.

**Prompt:**

"Help me organize a case study for an AI-assisted portfolio website project. Include the problem statement, objectives, technology stack, AI workflow, prompt design, testing, verification, before-and-after comparison, reviewer feedback, ethics, limitations, and conclusion. Mark missing evidence as pending instead of inventing results."

**Expected output:** A structured case-study outline.

**Verification:** Check the outline against the assignment requirements and add evidence as each activity is completed.

## 7. Prompt 6 — AI Output Verification

**Objective:** Identify claims that need checking.

**Prompt:**

"Review the following AI-generated portfolio content. Identify factual claims, unsupported assumptions, vague descriptions, invented achievements, privacy concerns, and statements that need evidence. Do not assume a claim is true merely because it sounds plausible. Return a table containing the original claim, the concern, how to verify it, and the correction needed."

**Expected output:** A verification checklist.

**Verification:** Independently check factual claims and document the corrections made.

## 8. Prompt 7 — Ethical and Privacy Review

**Objective:** Review content before publication.

**Prompt:**

"Evaluate this student portfolio for responsible AI use, privacy, copyright, accuracy, and transparency. Identify potential problems and recommend practical corrections. Do not reproduce private information unnecessarily. Distinguish general recommendations from issues actually found in the supplied content."

**Expected output:** An ethics review and list of recommended corrections.

**Verification:** Review each recommendation and document the actions taken.

## 9. Prompt Engineering Principles

The prompts in this library use the following principles:

- **Role:** Define the AI's task or role.
- **Context:** Supply relevant project and student information.
- **Task:** State exactly what the AI should do.
- **Constraints:** Specify length, tone, and prohibited claims.
- **Output format:** Request a particular structure when useful.
- **Verification:** Require human review before publication.

### Evaluation Criteria

Each tested prompt will be assessed for:

1. **Accuracy:** Does the output reflect the facts supplied?
2. **Relevance:** Does it meet the intended portfolio task?
3. **Clarity:** Is the result understandable and well organized?
4. **Unsupported claims:** Does it invent skills, achievements, or completed work?
5. **Editing required:** What corrections were necessary before using the output?

### Best Prompt Selection

The best prompt will be selected after comparing actual outputs. Selection will be based on factual accuracy, relevance, clarity, and the amount of human correction required.

No prompt will be described as tested or best-performing until its output has been reviewed.
