# AI Prompt Library
## AI Portfolio Website Content Creator

**Student:** Syed Umar T  
**Course:** B.Tech Information Technology — Second Year

## Prompt 1: Personal Introduction

**Goal:** Create a professional introduction.

**Prompt:**
Write a concise introduction for Syed Umar T, a second-year B.Tech IT student interested in software development and artificial intelligence. My current skills are HTML, CSS, and Python. Do not invent achievements or experience.

**Verification:** Check that all details accurately represent my background.

## Prompt 2: About Me

**Goal:** Create an About Me section.

**Prompt:**
Write an About Me section for a second-year B.Tech IT student interested in software development and AI. Use clear, professional language and mention HTML, CSS, and Python. Do not invent personal achievements.

**Verification:** Review the text for accuracy and clarity.

## Prompt 3: Project Description

**Goal:** Describe my capstone project.

**Prompt:**
Write a project summary for my AI Portfolio Website Content Creator capstone. The website uses HTML and CSS and is hosted on GitHub Pages. Explain how AI can assist with portfolio content creation and verification. Do not claim that planned activities have already been completed.

**Verification:** Compare the description with the actual project.

## Prompt 4: Content Improvement

**Goal:** Improve grammar and readability.

**Prompt:**
Review the following portfolio text for grammar, clarity, and professional tone. Preserve its meaning. Do not add unsupported skills, achievements, or experience. Explain the main changes.

**Verification:** Compare the revised text with the original.

## Prompt 5: AI Output Verification

**Goal:** Identify possible errors.

**Prompt:**
Review the following AI-generated content. Identify unsupported claims, factual errors that require checking, vague descriptions, and privacy concerns. Suggest corrections in a table.

**Verification:** Independently check claims before publishing.

## Prompt Engineering Principles

- Provide context about the task.
- State the goal clearly.
- Specify the required tone and length.
- Set limits to prevent invented claims.
- Request a useful output format.
- Verify and edit AI-generated content.

## Testing Log

For each prompt, record:

- Prompt ID
- AI tool used
- Date tested
- Output generated
- Errors identified
- Corrections made
- Final decision

## Ethics and Limitations

AI may generate inaccurate, generic, or misleading content. Human review is necessary. Personal information must be protected, factual claims must be checked, and image or text licensing must be considered.

## Conclusion

This prompt library documents a repeatable approach to AI-assisted portfolio writing, verification, and responsible content creation.
