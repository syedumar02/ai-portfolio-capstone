## 4. AI Hallucination Analysis

An AI hallucination occurs when an AI system generates unsupported, misleading, or incorrect information.

Potential risks in this project include:

- Claiming a skill the student does not possess.
- Inventing achievements, work experience, or certifications.
- Describing planned features as completed.
- Claiming an AI tool was used when it was not.
- Presenting AI-generated feedback as independent feedback from real people.
- Making unsupported statements about licensing, privacy, or security.
- Describing the project as an automatic content-generation application when the implemented project is a personal portfolio created with AI-assisted content review.

### Risk Mitigation

| Potential Risk | Mitigation |
|---|---|
| Incorrect personal information | Compare content against the student's actual details. |
| Exaggerated skills or experience | Use accurate descriptions of current skills and learning goals. |
| Unsupported project claims | Compare descriptions with the actual website and repository. |
| Incorrect AI-generated suggestions | Review suggestions before accepting them. |
| Copyright concerns | Use original wording where possible and check permissions for third-party assets. |
| Misrepresentation of reviewer feedback | Clearly distinguish AI-generated review suggestions from feedback supplied by actual people. |
