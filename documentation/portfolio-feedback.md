# Portfolio Review and Feedback Report

## Review 1 – Website Design

**Feedback:**

The website looks neat, and I like the banner at the top. The sections are easy to find, and the Projects section gives a clear idea of what the website is about. It would be worth checking the website on a mobile phone to make sure everything looks good on a smaller screen.

**Suggested Improvement:**  
Check the mobile layout and fix any spacing or display issues if needed.

## Review 2 – Content and Information

**Feedback:**

The About section explains the student's background and interests clearly. I also liked that there is a separate page for the case study. Adding more details about the work completed and what was learned while building the website would help visitors understand the effort involved.

**Suggested Improvement:**  
Include specific examples of completed work and lessons learned from using AI tools.

## Review 3 – Documentation and Testing

**Feedback:**

The documentation covers important parts of the project, including AI tools, testing, and privacy. Some sections describe planned work rather than completed activities. Adding actual test results and examples of how the content was improved would make the documentation stronger.

**Suggested Improvement:**  
Include real testing results and examples showing the original content alongside the revised version.

## Overall Review

The portfolio is a good start and presents the project in a simple, understandable way. The banner and page structure make it easy to explore, while the case study explains the project's purpose. The main areas for improvement are mobile testing, providing more details about completed work, and including evidence of testing and AI-assisted editing.

Addressing these suggestions would make the portfolio more complete and help demonstrate the work involved in the capstone project.

**Note:** These are review perspectives prepared to identify potential improvements. They should not be presented as independent feedback from three actual reviewers unless those people have reviewed the portfolio.
